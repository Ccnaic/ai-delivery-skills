# 把坑变成规则（encode-lessons）

**一句话：三次犯同一个错，就把它写成让构建失败的规则。**

> 为什么：`failures.md` 是"人读的清单"，靠自觉。
> 规则是"系统强制的约束"，靠机器。
>
> **靠自觉的东西，换个会话就忘了。靠机器的，永远在。**

---

## 核心原理

> **Agent 永远走阻力最小的路径。**
> **所以让"最容易的路径"和"唯一正确的路径"重合。**

举例（真实做过）：

| 问题 | 变成的规则 |
|---|---|
| Agent 老写没用的注释 | CI 直接禁止普通注释，写了构建就红 |
| Agent 把主进程和渲染进程的代码混着 import | CI 检查依赖图，跨目录 import 直接失败 |
| 某个 bug 在评审里被指出过三次 | 变成 lint 规则，代码里再出现就编译不过 |

**不是提醒它"注意点"，是让错误写法直接跑不起来。**

---

## 三步

### 第一步：记录（已经在做）

```markdown
| 日期 | 缺陷 | 根因 | 犯过几次 |
|---|---|---|---|
| 11-04 | 8 秒截图实际只有 1.7 秒 | 用帧数当时间 | 1 |
| 11-04 | glTF 改名后测试仍 PASS | .import 缓存仍在 | 1 |
```

**关键字段：犯过几次。** 只犯一次的先记着，不急着立规矩——过早立规矩会把系统搞僵。

### 第二步：分类

每次记录后，问一个问题：

```
这个错，能不能被机器自动检测出来？
```

| 能 → | 不能 → |
|---|---|
| 写成 lint / 测试 / CI 检查 | 写进 checklist，人工把关 |

**判断标准**：能不能用一行代码判断"这次犯了没有"。

```
✅ 能自动检测：
   "用了帧数当时间"      → 搜 `frames` 出现在计时代码里
   "标题用了三级井号"    → 正则行首锚定
   "跨目录 import"       → 检查依赖图

❌ 不能自动检测：
   "设计得不好看"        → 只能人看
   "需求理解偏了"        → 靠菜谱 + 复述确认
```

### 第三步：转化（能自动的那部分）

**三个层次，从轻到重：**

```
① 断言     一条测试，跑的时候检查
② 检查     提交前 / 构建时跑，不通过就红
③ 结构     让它根本写不出来（改架构、拆目录、删 API）
```

**优先级：能用③就不用②，能用②就不用①。**

因为：断言可以被跳过，检查可以被绕过，**结构改完之后根本写不出来**。

举例：

```
① 断言：测试里检查"有没有加注释"
② 检查：CI 跑一个 grep，发现注释就失败
③ 结构：把注释这个语法从构建链里去掉，写了也编译不过
```

**做得越靠后，越不会再犯。**

---

## 转化之后必须验证

**规则写完，故意犯一次，看它会不会红。**

```
写完 lint 规则 → 故意写一段违规代码 → 跑检查
   → 报错了：规则有效
   → 没报错：规则写错了，或者根本没生效
```

**没验证过的规则，等于没写。** 这跟"没跑过的测试"是同一类错误。

---

## 什么该立规矩，什么不该

| 该立 | 不该立 |
|---|---|
| 犯过 3 次以上 | 只犯过 1 次 |
| 能机械检测 | 靠主观判断（"要好用"） |
| 违反后果严重（数据丢失、交付失败） | 违反只是不够优雅 |
| 有明确的正确写法 | 有多个合理写法 |

**规矩太多会把系统搞僵。** 只对"反复发生且危害明确"的错立规矩。

---

## 规矩的维护

```
每条规则要带：
- 来源（哪次事故）
- 检测方式（怎么判）
- 例外情况（有没有合理的破例）
- 生效日期
```

**定期清理**：如果一条规则半年没人违反、也没人抱怨，考虑删掉——它可能在防一个不存在的问题。

---

## 常见坑

| 坑 | 后果 | 防法 |
|---|---|---|
| 只记录不转化 | failures.md 越来越长，错误照犯 | 犯第 3 次时必须转化 |
| 转化了不验证 | 以为有规则，其实没生效 | 故意违规一次，看它红不红 |
| 立太多规矩 | 系统僵化，正常活也干不了 | 只立"重复 + 危害明确"的 |
| 规则没有例外条款 | 合理场景被误伤 | 每条规则写清例外 |
| 靠人记住 | 换个会话就忘 | 必须落成机器可执行的检查 |

---

## 一句话

> **文档记得住，人记不住。**
> **所以重要的不是"写下来"，是"让违反它的东西跑不起来"。**
