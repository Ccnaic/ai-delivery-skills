# examples

## `cli-ledger/` — 一次完整运行的产物（可复现）

任务：「做一个命令行记账工具，能记一笔、查余额、看记录。做得实用点。」
规模：749 行 Python / 13 分钟 / deepseek-v4.1-flash

**能直接跑，不是示意**：

```bash
cd cli-ledger
python verify.py           # 期望 20/20 PASS, exit 0
python mutation_test.py    # 期望 19/20 FAIL —— 这是对的
```

里面包含：需求菜谱、切块方案（含无主需求回查）、逐条打勾、验证工具、变异测试、原始证据。

**最值得看的是 `cli-ledger/SWARM-PLAN.md` 里「A4 回查：每条需求归谁」那一节。**

它抓出了 4 条不属于任何技术模块的需求（默认数据路径、根入口、README、验证脚本），单独成块 C。
不这么做，这 4 条会在切块时直接掉出去——而按模块统计还会显示「全部完成」。

`cli-ledger/PROBLEMS.md` 记录了执行时「skill 说不清、只能猜」的 15 处，**那比产出本身更有用**。
